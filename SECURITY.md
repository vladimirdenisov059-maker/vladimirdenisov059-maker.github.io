# Security Policy

## Supported version

Поддерживается текущая версия ветки `main`.

## Reporting a vulnerability

Не публикуйте секреты и персональные данные в Issues. Сообщите владельцу через контактные ссылки на странице `/contacts/`.

## Current controls

- статическая генерация без базы данных и серверной формы;
- CSP, запрет внешних скриптов и внешних шрифтов;
- автоматический npm audit и Dependabot;
- GitHub Actions с минимальными разрешениями и закреплёнными commit SHA;
- изображения и видео очищаются от исходных метаданных;
- сайт временно исключён из индексации поисковиками.
