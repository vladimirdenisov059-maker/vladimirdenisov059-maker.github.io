# Фотографии сайта

Положите оптимизированные фотографии в подпапки:

- `author/` — портрет и фотографии Владимира;
- `garden/` — общие виды сада;
- `plants/<slug>/` — фотографии конкретной культуры;
- `articles/<slug>/` — обложки и галереи статей;
- `experiments/<slug>/YYYY/` — хронология экспериментов по годам.

Используйте латиницу, нижний регистр и дефисы: `kivi-stratona-cvetenie-2026-01.jpg`.
Исходные полноразмерные файлы храните отдельно. Для сайта предпочтительны WebP/AVIF и JPEG с разумным сжатием.
