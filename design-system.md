# Дизайн-система

## Характер

«Полевой дневник зрелого сада»: спокойный, доказательный, тёплый. Интерфейс не имитирует Дзен и не использует стоковые фотографии как авторские.

## Палитра

- `#173d2d` — основной лесной зелёный;
- `#245540` — интерактивный зелёный;
- `#f4f0e6` — бумажный фон;
- `#ebe4d4` — вторичный фон;
- `#20251f` — основной текст;
- `#9d3b2f` — яблочно-красный акцент;
- `#d8a84e` — медовый focus и декоративный акцент.

## Типографика и сетка

Заголовки: Literata с системным fallback Georgia. Интерфейс: Manrope с Arial fallback. Контейнер до 1180 px, интервалы адаптивные через `clamp()`. Основной текст не шире 760 px.

## Правила компонентов

Минимальная интерактивная зона — 42–48 px. Focus всегда заметен. Карточка имеет один основной заголовок-ссылку. Фото без исходника заменяется явно подписанной заглушкой. Движение отключается через `prefers-reduced-motion`.
