# Закрытый редактор Владимира

Страница редактора создаётся по адресу `/studio-vd/`, не имеет ссылки в меню и исключена из sitemap. Сам адрес не является средством защиты: все серверные действия требуют пароль владельца.

## Что уже работает

1. Генерация подробного поста для ВКонтакте от первого лица.
2. Приоритет опубликованного опыта из архива сада.
3. Поле для новых наблюдений автора.
4. Ручное редактирование, копирование и сохранение черновика в TXT.
5. Отдельное одобрение и дополнительный вопрос перед публикацией.
6. Защита от повторной отправки одного поста через `guid` ВКонтакте.

## Обязательная настройка закрытого входа

В Cloudflare Pages, проект `gardens-of-donbas-api`, открыть **Settings → Variables and Secrets** и добавить encrypted secret:

- `ADMIN_PASSWORD` — отдельный надёжный пароль длиной не менее 16 символов; используйте латинские буквы, цифры и знаки.

Пароль нельзя записывать в GitHub, `.env.example` или переменную с префиксом `PUBLIC_`.

## Подключение ВКонтакте

До подключения ВК редактор создаёт, редактирует, сохраняет и копирует черновики, но кнопка публикации остаётся выключенной.

Для публикации потребуются настройки Cloudflare:

- `VK_ACCESS_TOKEN` — encrypted secret с правом публикации на стене;
- `VK_OWNER_ID` — числовой ID личной страницы или отрицательный ID сообщества;
- `VK_API_VERSION` — необязательная переменная, по умолчанию `5.199`.

После изменения секретов нужно повторить последнее развертывание Cloudflare Pages. Токен ВК нельзя вводить на странице редактора или хранить в GitHub.
