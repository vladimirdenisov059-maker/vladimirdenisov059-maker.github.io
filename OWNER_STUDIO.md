# Закрытый редактор Владимира

Редактор находится по адресу `/studio-vd/`, не указан в меню и исключён из sitemap. Адрес сам по себе не является защитой: генерация, проверка ВК, загрузка файлов и публикация требуют пароль владельца.

## Что работает

1. Подробный авторский пост для личной страницы ВКонтакте.
2. Приоритет опубликованного опыта из архива сада.
3. Поле для новых наблюдений автора.
4. Ручное редактирование, копирование и сохранение черновика в TXT.
5. Выбор и предварительный просмотр нескольких фотографий и видео.
6. Загрузка до 10 вложений непосредственно перед отправкой поста.
7. Два режима: публикация сразу либо постановка в очередь ВК на выбранные дату и время.
8. Отдельное подтверждение текста, вложений и времени.
9. Защита от повторной отправки одного поста через `guid` ВКонтакте.

## Секреты Cloudflare Pages

Проект: `gardens-of-donbas-api` → **Settings → Variables and Secrets**.

- `PROXYAPI_KEY` — ключ генерации текста, encrypted secret.
- `ADMIN_PASSWORD` — пароль владельца длиной не менее 12 символов, encrypted secret.
- `VK_ACCESS_TOKEN` — пользовательский токен ВКонтакте, encrypted secret.
- `VK_OWNER_ID` — положительный числовой ID личной страницы Владимира.
- `VK_API_VERSION` — необязательно, по умолчанию `5.199`.
- `REVIEW_PASSWORD` — необязательный временный пароль для проверяющего (например, преподавателя интенсива), длиной не менее 12 символов.
- `REVIEW_EXPIRES_AT` — обязателен вместе с `REVIEW_PASSWORD`: ISO-дата и время, после которых временный пароль перестаёт работать (например, `2026-08-03T23:59:59+03:00`).
- `OK_APPLICATION_KEY`, `OK_APPLICATION_SECRET_KEY`, `OK_ACCESS_TOKEN` — доступ к API Одноклассников, encrypted secrets.
- `OK_GROUP_ID` — числовой ID вашей группы (публичной страницы) в ОК, куда публикуются записи.

### Получение доступа к API Одноклассников

Классическая регистрация REST-приложения через `ok.ru/vitrina/vk` для новых приложений закрыта — ОК принимает только **VK Mini App, опубликованное в ОК** через dev.vk.com. Поэтому процесс такой:

1. В [dev.vk.com](https://dev.vk.com) уже создано Mini App «Экзотический сад Донбасса» (VK ID `54704308`) и через раздел «Другие площадки» опубликовано в ОК (OK ID `512005340310`).
2. В ОК создана публичная группа «Экзотический сад Донбасса» (`OK_GROUP_ID = 70000055666856`), куда идёт публикация.
3. `OK_APPLICATION_KEY` / `OK_APPLICATION_SECRET_KEY` — «Публичный ключ» и «Защищённый ключ» со страницы настроек Mini App в dev.vk.com (раздел «Другие площадки» → ОК).
4. `OK_ACCESS_TOKEN` нельзя получить обычным OAuth-редиректом — у Mini App, опубликованных в ОК, такого поля нет. Вместо этого:
   - откройте страницу `/studio-vd-ok-token/` **изнутри самого приложения ОК** (запустив Mini App из ленты/каталога ОК, а не по прямой ссылке в браузере);
   - нажмите кнопку «Получить токен ОК» — она вызывает `VKWebAppGetAuthToken` через VK Bridge с правами `wall,groups,photos,video`;
   - скопируйте появившийся токен и сохраните как `OK_ACCESS_TOKEN` в секретах Cloudflare.
   - Токен привязан к вашему аккаунту ОК и долгоживущий, повторять эту процедуру нужно только если токен перестанет действовать.

После первой настройки обязательно проверьте связку через кнопку «Проверить подключение ОК» в редакторе, прежде чем нажимать «Опубликовать».

`VK_ACCESS_TOKEN` должен принадлежать владельцу личной страницы и разрешать публикацию на стене, работу с фотографиями и видео. Токен нельзя вводить в редакторе, сохранять в GitHub, `.env.example` или переменной с префиксом `PUBLIC_`.

После изменения секретов повторить последнее развёртывание Cloudflare Pages.

## Временный доступ для проверяющего

Пароль из `REVIEW_PASSWORD` работает как обычный пароль редактора (генерация черновика, просмотр подключения ВК, просмотр истории), но:

- перестаёт приниматься после момента `REVIEW_EXPIRES_AT`;
- не может опубликовать реальный пост на стене (`/api/owner/publish-vk` вернёт ошибку 403);
- не может загрузить файл во ВКонтакте (`/api/owner/upload-vk-media` вернёт ошибку 403);
- не может добавлять записи в историю публикаций (только просматривать).

Чтобы выдать разовый доступ: задать оба секрета, передать `REVIEW_PASSWORD` проверяющему, после истечения срока удалить оба секрета из Cloudflare (не обязательно, но аккуратнее).

## Проверка подключения

После создания черновика редактор вызывает защищённый обработчик `/api/owner/vk-status`. Он обращается к `users.get`, сверяет токен с `VK_OWNER_ID` и показывает имя подключённой страницы. Секретный токен браузеру не возвращается.

Аналогично для ОК: `/api/owner/ok-status` обращается к `users.getCurrentUser`. Если секреты ОК не заданы, кнопка публикации всё равно публикует пост во ВКонтакте — публикация в ОК просто пропускается без ошибки.

## Публикация в Одноклассники

Кнопка «Опубликовать» в редакторе Владимира одна на обе площадки: если подключение ОК настроено и режим публикации — «сразу» (не отложенный), после успешной публикации во ВКонтакте редактор автоматически загружает те же вложения в ОК (`photosV2.getUploadUrl` / `video.getUploadUrl`) и публикует запись через `mediatopic.post` в группу `OK_GROUP_ID`. Отложенная публикация (`publish_date`) для ОК не реализована — если выбрано время в будущем, запись в ОК нужно будет создать вручную позже.

Если публикация в ОК не удалась, статус ВК всё равно останется засчитанным — ошибка ОК просто добавляется отдельной строкой, а в историю публикаций попадает отдельная запись с платформой `ok` и статусом `error`.

## Дзен

У Дзена нет открытого API для публикации от лица обычного (не медийного) канала, поэтому для него в редакторе есть только вспомогательный шаг: кнопка «Скопировать текст для Дзена» копирует одобренный текст поста. Фотографии и видео уже лежат у вас на компьютере (это те же файлы, что вы выбрали в шаге 3) — их нужно вручную прикрепить в редакторе Дзена.

## Публикация по расписанию

Редактор переводит выбранные пользователем локальные дату и время в Unix timestamp и передаёт его в `wall.post` как `publish_date`. Очередь хранится во ВКонтакте, поэтому после успешной постановки компьютер и браузер можно выключить.

Разрешены даты от одной минуты до одного года вперёд. Перед постановкой в очередь пользователь отдельно подтверждает дату и время.

## Медиа

- Фотографии: JPG, PNG, WebP, до 25 МБ каждая.
- Видео: MP4, WebM, MOV, MKV, до 95 МБ каждое.
- Общий лимит редактора: 10 файлов на пост.

Файлы передаются по одному через потоковый Cloudflare Pages Function. Для фотографии используются `photos.getWallUploadServer` и `photos.saveWallPhoto`; для видео — `video.save`. Полученные идентификаторы передаются в `wall.post` через `attachments`.

Лимит видео выбран ниже стандартного предела тела запроса Cloudflare Free. Для более крупных роликов в следующей версии следует добавить выбор уже загруженного во ВКонтакте видео по ссылке.
